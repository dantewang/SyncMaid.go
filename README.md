# SyncMaid.go

SyncMaid 是面向 Windows 的单向文件同步工具。目前支持在原生窗口输入或选择一个源与一个目标文件夹，创建本次手动任务并运行仅添加同步，查看进度、结果或停止。任务只保留在会话内，不读取、保存或迁移旧版任务配置；镜像删除、移动、调度和多目标尚未接入。

仅添加会复制缺失文件，并更新大小或整秒修改时间不同的文件，不删除目标额外文件；大小和整秒修改时间相同则跳过，不逐个比较内容。新内容先写目标旁临时文件并校验，再原子发布；失败或停止保留已发布文件，不回滚整个任务，可能留下本次新建的空父目录。发布调用报错而结果无法确认时会保留文件对象并提示检查，不自动删除或认定成功。源、目标必须已存在且不重叠，目前仅接受本地固定 NTFS/ReFS；子级链接、硬链接文件及区分大小写的目录暂不支持。请避免同时用其他程序编辑同步目录；这不是文件系统快照或外部编辑的事务。

关闭窗口会隐藏到托盘并保持任务运行；托盘图标点击及菜单 Show main window 的恢复操作尚待人工验收。Exit 会先停止任务、清理临时文件再退出；异常存储驱动仍可能延迟系统 I/O 完成。同一目录再次启动会恢复已有窗口；不同目录的副本可独立运行。数据目录固定为可执行文件所在真实目录旁的 `Data`，目前不加载旧版任务或设置。

安装目录与 Data 必须可写，程序会在其中建立并保留 `.syncmaid-owner.lock`，不要在运行时修改。当前仅接受本地固定 NTFS/ReFS 卷；USB、网络位置的便携运行仍是待补齐的能力，当前会拒绝启动。窗口激活失败不会允许第二个写入实例；此机制尚不与 Rust 旧版协调。

启动失败时会显示原生提示，说明相关位置和可采取的下一步。正常再次启动只恢复已有窗口；若未能确认恢复，会提示查看已有窗口、稍后重试或从托盘恢复，不会接管 Data。

## 编译与运行

需要 Go **1.27.3**（当前过滤 profile 固定此版本）。项目固定使用 MyGo **v0.8.3**，无需 Bun、WebView2 或 cgo 工具链。

在项目根目录使用 PowerShell，自行准备依赖并编译：

```powershell
$env:GOTOOLCHAIN = 'local'
$env:CGO_ENABLED = '0'
go mod tidy
New-Item -ItemType Directory -Force build | Out-Null
go build -ldflags=-H=windowsgui -o build/SyncMaid.exe .
.\build\SyncMaid.exe
```

首次执行 `go mod tidy` 需要访问 Go 模块源，下载依赖并生成 `go.sum`。构建成功后运行程序，应显示 SyncMaid 启动窗口。

## 测试

```powershell
go test ./...
go vet ./...
```

现有测试覆盖传输失败与取消、已有文件保护、路径边界、无头视图、目录身份、生命周期和文件过滤。只读扫描完整成功后才开始同步。过滤和正则迁移、四语界面仍未接入此手动流程；中文输入法组合过程也未验收。

当前窗口骨架已验证无 cgo 构建、关闭隐藏、重复启动恢复、跨目录独立运行与退出。`go tool mygo build -skip-installer` 可生成不含安装器的 Windows 发布目录，当前骨架的单个 EXE 复制后可运行。新增外部资源时仍需明确嵌入方式；托盘鼠标操作、不同 DPI 和干净 Windows 环境兼容尚待验证。
