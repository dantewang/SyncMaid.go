## 看懂任务与目标状态

| 状态显示 | 含义 |
|---|---|
| **从未运行** | 添加后尚未完成过运行。 |
| **扫描源文件夹** / **同步中** / **移动中** | 正在运行当前阶段，界面会展示进度和字节统计。 |
| **等待删除确认** | Mirror 检测到目标有多余文件，正在等待你点击**确认本次移除**或**取消本次移除**。 |
| **全部已同步** / **已完成** | 任务下所有目标顺利完成。 |
| **部分目标已完成** | 多个目标结果不一致（或存在无匹配文件 / 冲突保留文件）。 |
| **失败 · `<原因>`** | 该目标执行失败并给出具体原因；同任务中其他独立目标不会因此中断。 |
| **已停止** | 用户主动取消了运行，已完成的目标成果保留，临时文件已清理。 |
| **中断/结果未知（未记录结束）** | 历史记录中存在只记了开始、没记结束的异常中断（例如掉电或强杀进程），请人工核对文件状态。 |

## 常见问题排查

### 卡片显示“触发器异常”

表示该任务的 **Watch** 或 **Scheduled** 自动触发遇到错误（通常是源目录不存在、移动硬盘未插入或网络共享断开）。恢复源目录访问后，Watch 会在 30 秒后自动重试恢复，也可**编辑任务 → 保存任务**立即重建触发器；手动**运行**始终不受限制。

### 定时或监视任务没有自动触发

- 确认任务下**至少包含一个目标**（`尚未添加目标` 的任务不会注册后台触发器）。
- 检查左下角 **更多操作** 是否开启了**暂停自动触发**（开启时主界面顶部会出现“自动触发已暂停”横幅）。
- 如果你会关闭主窗口并希望自动任务继续跑，请确认 **设置 → 窗口 → 关闭到托盘**已开启。
- 对于 **Watch**：默认有 10 秒**静默秒数**，需要源目录停止变动满整段静默期后才会触发。
- 对于 **Scheduled**：电脑休眠或程序关闭期间错过的定时点**不会补跑**，只会等待下一个计划时刻。

### 文件没有同步到某个目标

- 检查**此目标的文件过滤**，可在目标编辑页点**源预览**直接看匹配数；如果模式选了**无匹配**或**仅匹配**规则未命中任何文件，目标不会收到文件。
- 在 **Move** 任务中，先检查目标列表顺序是否被排在前面的规则抢先命中，或因**保留源**冲突策略跳过。
- 如果文件正被其它软件独占锁定，Move 会保留源文件并记录失败，待解锁后再次运行即可移动。

### 编辑器阻止保存或运行拒绝目录路径

SyncMaid 禁止源与目标之间、同一任务多个目标之间、以及跨任务之间存在重叠、相同或互相嵌套的路径（包含 Windows 目录联接点与路径别名）。请检查相关任务的目录设置，确保彼此目录树完全独立；如需串联流转，只允许“任务 A 的目标 = 任务 B 的源”这种清晰单向级联。参见 [路径规则](tasks-and-destinations.md#syncmaid-强制校验的路径规则)。

### 提示“此任务不可运行或编辑” / 规则只读

- 从旧版导入且包含**旧正则表达式**或复杂结构的过滤规则会以只读保留，在完成人工审查前不允许运行。选中任务后在 **更多操作 → 旧正则迁移** 中完成新引擎预览与确认保存。
- 若 `tasks-go.json` 被损坏或外部篡改，请修复磁盘文件或使用界面上的**恢复任务备份**功能，再点 **更多操作 → 重新载入**。

## 查看运行记录与同步日志

SyncMaid 将结构化运行记录保存在 `Data\run-history-go.json`，并将应用日志写入 `Data\logs\`：

- 点击任意目标行右侧的**状态文字**（例如 `1分钟前同步 · 2个文件`），即可打开该目标的**同步日志**独立窗口：
  - 展示该目标**最近 20 条运行记录**及详细计数（源、匹配、已发布、移动、移除、保留/待核对、未变化、移动失败、源未匹配、字节数）。
  - 点击**诊断详情**可展开任务 ID、目标 ID 与完整的 `run-history-go.json` 路径。
  - 点击**刷新**只从磁盘重新读取最新记录，不会重试执行同步。
  - 点击**打开日志文件**可用系统默认关联程序打开 `run-history-go.json`。
- 在主窗口 **更多操作 → 查看运行记录** 中也可以浏览最近各任务的全局记录。

## 重置配置

- 在应用内删除任务**仅移除 `tasks-go.json` 中的记录，源和目标里的实际文件完全不动**。
- 如果需要彻底重置全部配置，请先完全**Exit**退出 SyncMaid，再检查或删除 `SyncMaid.exe` 同级 `Data\` 文件夹下的 `tasks-go.json`（及 `.bak` 备份）、`settings-go.json`、`locale` 和 `run-history-go.json`。
