# 过滤规则

[English](../filters.md) | 简体中文

过滤规则决定**源目录中哪些文件会被分发到某个具体目标**，在目标编辑器中的**此目标的文件过滤**下配置。

目标编辑器提供三种模式：

- **所有文件**：同步源目录中的全部常规文件（默认）。
- **无匹配**：该目标暂时不接收任何文件（也不会删除目标里已有的文件）。
- **仅匹配**：通过下面的包含/排除条件组精确筛选。

> **Mirror镜像固定同步所有文件**：使用 Mirror 策略前必须先设为**所有文件**；选择 Mirror 后过滤选项会保持锁定。

## 包含 / 排除条件组（仅匹配）

点击**仅匹配**后，可以构建一层或多层规则组：

- **组间逻辑**（存在多个组时）：**全部组**（AND，需同时满足所有组）或**任一组**（OR，满足至少一个组即可）。
- **组内逻辑**：**全部规则**（AND）或**任一规则**（OR），并可为每条规则单独切换**包含** / **排除**。
- **规则类型**（文本框内每行一项，自动忽略空行与首尾空白）：
  - **路径前缀**：相对于源目录的子目录前缀（例如 `photos/2024` 匹配 `<源>\photos\2024` 下的文件）。
  - **扩展名**：文件扩展名（例如 `jpg` 匹配所有 `.jpg` 文件，无需手写点号）。
  - **通配符**：相对路径匹配模式（自动忽略大小写，反斜杠 `\` 等同于 `/`）：
    - `*`：匹配单级目录内的任意字符（不跨目录 `/`）
    - `?`：匹配单个字符（不跨目录 `/`）
    - `**`：匹配任意层级子目录（包含零层）

| 通配符模式 | 匹配示例 |
|---|---|
| `**/ChatGPT*.png` | 任意深度的 `ChatGPT 1.png`、`saved/ChatGPT-2.png` |
| `photos/*.raw` | 仅 `photos/a.raw`，**不含** `photos/2024/a.raw` |
| `photos/**/*.raw` | `photos\` 下任意深度的所有 `.raw` 文件 |
| `photos/**` | `photos\` 下的所有文件 |
| `IMG_????.jpg` | 源根目录下的 `IMG_0042.jpg` |

## 源预览

在目标编辑区中，可以随时点击**源预览** / **刷新预览**，在真正写入或保存前对当前源草稿执行只读预扫描：

- 显示源目录文件总数（或明确区分“空目录”与“目录存在但无常规文件”）。
- 显示各目标预计匹配的文件数量与代表路径、**未匹配**文件统计；对 Move 任务还会标出**多规则匹配（首匹配生效）**的文件。
- 统计源目录中高频**扩展名快捷芯片**，点击即可将该扩展名直接填入当前正在编辑的条件组。

源预览严格只读，不修改任何文件，也不会刷新/代替正则确认。

## 规则摘要显示

主卡片和目标行会显示规则摘要（如`所有文件`、`无规则`或条件概括）。当模式选择为**仅匹配**但还未填入有效规则时，保存与预览都会提示**过滤规则不能为空**。

## 旧版正则表达式（Regex）规则与迁移

新版 Go 过滤编辑器本身**不支持直接新增正则表达式输入**。

如果你加载或通过**导入旧任务**引入了旧版 `tasks.json` 中包含 `regex`（或复杂嵌套规则）的目标：

- 这些规则会被原样保留并在过滤界面中标记为**只读**，绝不会悄然降级或丢失。
- 含有未确认旧正则规则的目标（对于 Move 则是整个任务）会**阻止执行**，直到完成人工迁移确认。
- 选中该任务后打开左下角 **更多操作 → 旧正则迁移**，可以在新正则引擎下填写最多 16 行示例路径执行**预览新正则**，确认行为无误后点击**确认新语义并保存**。

迁移后所使用的 Go 正则引擎（RE2 `regexp`）关键语义说明：

- 默认忽略大小写（可用 `(?-i)` 开启区分大小写）；相对路径中的 `\` 会规范化为 `/`；不支持前瞻/后顾（look-ahead / look-behind）与反向引用，且 `\w`/`\b` 等 Perl 字符类按 ASCII 语义处理。
- 确认记录绑定特定任务快照、规则与引擎 Profile 版本；之后若修改任务或表达式，须重新预览确认后方可执行。

## 过滤与策略的交互

- **仅添加（Add-only）**：仅影响后续复制哪些源文件；收窄过滤条件不会回溯删除目标里此前已复制的文件。
- **Move**：文件归属由**第一条匹配它的目标**独占，不匹配任何目标的文件继续留在源目录。
- **Mirror**：固定要求**所有文件**，不支持局部过滤。
