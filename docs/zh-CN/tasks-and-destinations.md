# 任务与目标

[English](../tasks-and-destinations.md) | 简体中文

一个**任务**由一个源文件夹、任务类型与触发器构成；一个**目标**代表一处接收文件的目标文件夹及其独立策略、选项和过滤规则。每个任务可以包含多个目标，也支持先以零目标保存任务框架再后续补充目标。

## 任务类型：同步（Sync）与移动（Move）

任务类型在新建任务时选定；只要任务下已有目标，就无法直接切换类型（因为 Sync 与 Move 的目标含义完全不同，如需切换须先移除全部目标）：

**Sync同步任务**将源目录中的匹配文件复制到目标目录，源目录保持原样。每个目标（**仅添加**或**Mirror镜像**）都会独立匹配整个源目录，因此同一文件可以分发给多个目标；各目标的失败与结果互不影响。

**Move移动任务**把源目录中的文件分拣并移走。所有目标构成一条**有序规则列表**：每个文件进入**第一条匹配它的目标**并在确认发布后从源中删除；没有匹配任何目标的文件保留在源目录。若某目标执行失败，文件**不会**顺延转投后续目标。

正因为“首匹配生效”，Move 的不同目标允许存在条件交集——使用目标行上的**上移** / **下移**按钮调整顺序会直接改变文件归属。把一个配置为**所有文件**的目标放在最后即可充当兜底规则。

## 任务卡片与界面控制

- **任务名与源路径**
- **触发器标识**：**Manual手动**、**Watch监视** 或 **Scheduled定时（`0 2 * * *`）**，并实时显示下次运行时间或监视状态
- **健康摘要**：**全部已同步**、**部分目标已完成**、**N个中有M个失败**、**尚未添加目标**
- **任务操作**：**运行** / **停止**、目标编辑、**编辑任务**、**删除任务**，以及卡片展开/折叠
- **目标列表行**：显示过滤与策略摘要、目标路径、最近同步状态（点击可打开**同步日志**窗口），以及行级操作按钮

主界面右上角提供**全部折叠** / **全部展开**、**运行全部**（按已保存顺序串行执行全部任务；点击**停止**会取消当前运行并清空剩余排队）以及**新建任务**。左下角**更多操作**菜单汇总了**运行全部**、**查看运行记录**、**重新载入**、**导入旧任务**、**旧正则迁移**、**暂停自动触发** / **恢复自动触发**与**Exit**。

## 同步策略

### 仅添加（Add-only）

> 复制新增和更改的文件；从不删除目标中的文件。

当源文件大小或整秒修改时间与目标不同时执行原子复制替换；从源目录删除的文件在目标端永久保留，适合只增不减的归档和双端可能手工写入的目标目录。

### Mirror镜像

> 复制新增和更改的文件；多余文件须每次确认后移除。

Mirror 让目标拥有与源一致的文件内容，并遵循以下严格门禁：

- **只能配合`所有文件`过滤**：选择 Mirror 前必须将目标过滤设为**所有文件**，启用后过滤控件锁定，避免“部分过滤的镜像”造成意外清空。
- **每次删除多余文件前须明确确认**：扫描发现源中已不存在的目标文件时，会弹出确认视图列出目标路径、删除方式（**移至回收站**或**永久删除（不可撤销）**）、待删除文件数和文件路径清单，只有点击**确认本次移除**后才真正执行删除，且确认仅对当次运行有效。
- **空源保护与空目录保留**：若源目录为空或不可访问，Mirror 会强制跳过全部删除以防误清空目标；此外，目标端既有的空目录会保持原样不清理。

### Move移动

> 首个匹配目标拥有文件；不覆盖目标，失败不转投后续目标。

Move 的关键行为如下：

- **源删除守卫**：只有目标临时文件完整写盘、校验并原子发布，且重新核验原始源文件句柄未发生变化后，才会删除源文件。
- **目录保留与平铺**：默认**保留目录结构**（如 `2026\a.pdf` → `Books\2026\a.pdf`）；切换到**平铺到目标根目录**后文件直接落入目标根目录（`Books\a.pdf`）。
- **冲突处理**：两种策略都不会覆盖目标里已有的同名文件：
  - **保留源**（默认）：遇到同名文件时跳过发布并保留源文件。
  - **加编号**：在扩展名前追加编号（如 `report (2).pdf`、`archive.tar (2).gz`），采用无替换原子发布并在遇到并发占用时有界重试。

## SyncMaid 强制校验的路径规则

以下约束在保存配置检查和实际打开 Windows 目录句柄时都会验证（可识别目录联接点/别名，防止绕过）：

1. **同一任务的源与目标不可重叠或互含**（例如 `D:\Photos` → `D:\Photos\Backup` 会被拒绝）。
2. **不同任务之间不得共用或嵌套源路径或目标路径**（因为不同任务可按各自的监视器与计划独立触发，重叠会导致竞态）。
3. **同一任务的多个目标之间不得相互重叠或嵌套**。
4. **允许任务级联**：任务 A 的目标可以作为任务 B 的源（例如先 Move 分拣，再由另一个任务 Sync 备份）。

## 编辑与删除

- **编辑任务**只修改任务级属性（任务类型（仅无目标时可改）、**任务名称**、**源文件夹**、**触发器**）。
- 打开目标工作区后，可对各目标行分别添加、复制、上移/下移、应用或单行取消，最后统一**保存**。
- 删除任务或目标前会弹出确认对话框，且**只修改 `tasks-go.json` 配置记录，绝不删除源或目标中的任何实际文件**。
