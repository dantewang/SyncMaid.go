# 触发器

[English](../triggers.md) | 简体中文

任务的**触发器**决定它在何时自动执行。每个任务在**新建任务** / **编辑任务**中设置一种触发方式；无论设置哪种触发器，随时点击任务卡片上的**运行**（或**更多操作 → 运行全部**）都可以立刻手动执行。

## Manual手动

仅当你手动点击**运行**或**运行全部**时执行，后台不建立任何目录监视或定时器。

## Watch监视

自动监听源目录的文件变化，并在变化稳定后触发一次同步：

- **静默期（静默秒数）**：可设为 **1–600 秒**，默认 **10 秒**。
- 在静默倒计时结束前如果又有新变化发生，计时会重置——适合保存文档、批量拷贝大目录时把一连串零散写入合并为一次完整同步。
- **网络目录/映射盘兼容**：对于 UNC 路径或映射网络驱动器，由于 Windows 原生目录通知不可靠，SyncMaid 会自动降级为周期轮询扫描并应用同样的静默期逻辑。
- **防自激守卫**：当前任务正在运行期间会自动暂停其自身监视器，任务结束后再重新建立，从而防止 Move 任务移走文件后又触发一次无意义运行。
- 当源目录暂时不可用（例如移动硬盘未插上）时，卡片会显示**触发器异常** / **监视失败，30秒后重试**，并在后台每隔 30 秒自动重试恢复。

## Scheduled定时

按照标准**五字段 Cron 表达式**，以你计算机的**本地时区**定时执行：

```text
分  时  日  月  星期（0–6，0 表示周日）
```

| 表达式 | 含义 |
|---|---|
| `*/5 * * * *` | 每 5 分钟执行一次 |
| `0 * * * *` | 每小时整点执行 |
| `0 2 * * *` | 每天 02:00 执行 |
| `0 2 * * 1` | 每周一 02:00 执行 |
| `30 22 1 * *` | 每月 1 日 22:30 执行 |

规则与限制：

- 仅接受五字段本地时间格式；不支持秒字段、年份、`?` 占位符以及 `TZ=` / `CRON_TZ=` 时区前缀。
- 输入表达式时界面会实时计算下一次执行时间；语法合法但无未来可执行时间（如 `0 0 30 2 *`）会给出明确提示。
- **不补跑历史（No catch-up）**：若预定时间到来时电脑休眠、程序未运行或系统唤醒延迟超过 5 秒，当次触发直接跳过，不积压历史执行，等待下一轮正常时间到来。

## 暂停自动触发与编辑态行为

- 可通过 **更多操作 → 暂停自动触发** 临时冻结当前会话内的所有 Watch 与 Scheduled 触发器；之后通过**恢复自动触发**重新激活并重算下一次运行时间。
- 正在编辑已有任务期间，该任务的自动触发会暂停，直至**保存任务**或**放弃编辑**。
- **尚未添加目标**（零目标）的任务不会在后台注册监视器或定时器。

## 运行中行为与停止

- 任务运行期间**运行**按钮会切为**停止**，并实时展示当前阶段（`扫描源文件夹`、`复制`、`校验`、`发布`或等待 Mirror 确认）。
- 点击**停止**会安全中止剩余工作：已完成的目标保留成果，传输中的临时文件被安全清理而不破坏目标原有文件，若处于**运行全部**队列中也会取消余下未运行任务。
- 同一任务绝不会并发重叠运行；运行途中新到达的自动触发会被合并处理。
