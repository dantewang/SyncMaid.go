# 设置与存储

[English](../settings.md) | 简体中文

点击左侧任务栏底部的齿轮图标（`⚙`）即可打开**设置**页。除特殊说明外，各项修改即时生效。

## 常规

### 界面语言

- 支持**系统默认**（跟随 Windows）、**English**、**简体中文**、**繁體中文**与**日本語**。
- 选择后立即切换全部界面文案，无需重启；配置持久保存在 `Data/locale` 中，切换语言不会改变任何任务名称、路径或正则确认状态。

## 启动

- **开机自启**：以当前目录中的 `SyncMaid.exe` 路径写入当前用户启动项（Windows 注册表 `HKCU\...\Run` 键下的 `SyncMaid.Go.<目录标识>`），可在 **Windows 任务管理器 → 启动应用**中直接看到与管理。
- 无需管理员权限。
- 如果你在系统任务管理器中手动禁用了 SyncMaid，界面会显示**已登记，但被系统禁用**，并尊重系统选择而不会强行覆盖启用状态。
- 如果把整个程序文件夹移动到了新路径，请重新切换一次自启开关更新登记路径。

## 窗口

- **关闭到托盘**（默认关闭）：
  - **开启**：点击窗口关闭按钮（`×`）时只隐藏窗口到系统托盘，后台 Watch/Scheduled 与当前同步继续工作。单击托盘图标或右键 → **Show main window** 可恢复窗口；通过托盘右键 → **Exit**（或主界面 **更多操作 → Exit**）才是真正退出。
  - **关闭**：关闭窗口即安全停止当前工作并退出程序。
- **启动时最小化**（默认关闭）：下次启动时直接以托盘小图标形式后台运行，不弹出主窗口。

## 存储

SyncMaid 采用**便携式存储**，所有运行和配置数据全部保存在 `SyncMaid.exe` 同级的 `Data` 目录内（要求位于本地固定或可移动 NTFS、ReFS、FAT/exFAT 分区）：

| `Data\` 下的路径 | 用途说明 |
|---|---|
| `tasks-go.json` | 已保存的任务、目标、过滤规则、触发器与 Go 正则确认记录 |
| `tasks-go.json.bak` | 由 `taskstore` 维护的自动备份文件 |
| `settings-go.json` | **关闭到托盘**与**启动时最小化**设置 |
| `locale` | 当前选择的界面语言（`Data/locale`） |
| `run-history-go.json` | 每任务最新运行状态及最近有界运行记录（最多保留 100 条） |
| `logs\` | 运行日志目录 |
| `cache\` | 运行期缓存目录 |

点击**打开数据目录**即可在资源管理器中直接定位到 `Data`。

### 多开限制与安装建议

- **放到可写目录**：不要放在没有写权限的 `Program Files` 等受保护位置，建议放在用户目录或其它可写盘符下。
- **同一 `Data` 目录单实例**：从同一目录再次启动 `SyncMaid.exe` 会直接唤醒并前置已有窗口，而不会并排打开两个进程同时写同一套配置文件。
- **不同目录互相独立**：把副本放到两个不同的文件夹里，它们各自拥有独立的 `Data` 与单实例标识，互不干扰。

## 从旧版（Rust `tasks.json` / 旧设置）导入

SyncMaid.go 使用独立的 Go 配置文件（`tasks-go.json`、`settings-go.json`），**绝不会自动修改或覆盖**原有的 `tasks.json` 或旧版设置：

- **导入旧任务**：通过左下角 **更多操作 → 导入旧任务**，选择旧版 `tasks.json`（或备份文件）查看预览，确认后会将任务以**Manual手动**模式追加到 `tasks-go.json`（旧文件及备份保持原样）。运行导入任务前请先退出旧版程序。
- **迁移旧窗口设置**：在 **设置 → 存储** 中点击**打开旧版设置或记录**，可选择性地仅导入旧版中的“关闭到托盘”和“启动时最小化”设置。
