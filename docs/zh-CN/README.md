# SyncMaid 使用指南

[English](../README.md) | 简体中文

了解如何使用 SyncMaid——面向 Windows 的单向文件同步工具：为单个源文件夹配置一个或多个目标，每个目标可独立设置过滤规则与策略，支持手动运行、本地 Cron 定时或监视源目录变更自动同步。

初次使用建议先看 [快速上手](getting-started.md)，几分钟即可完成第一个同步任务。

## 文档目录

- **[快速上手](getting-started.md)** — 运行便携版程序、创建第一个任务、添加目标并执行同步。
- **[任务与目标](tasks-and-destinations.md)** — Sync（同步）与 Move（移动）任务类型、Mirror/Add-only/Move 策略、多目标配置以及路径隔离规则。
- **[过滤规则](filters.md)** — 为每个目标筛选文件（`全部文件`、`无匹配`、`仅匹配` 包含/排除组）、源预览，以及旧版正则规则迁移。
- **[触发器](triggers.md)** — 手动运行、五字段本地时间 Cron 定时、以及目录变更监视与静默期防抖。
- **[设置与存储](settings.md)** — 界面语言、Windows 开机自启、托盘关闭/最小化行为、`Data` 便携目录文件说明，以及导入旧版任务。
- **[文件安全机制](safety.md)** — 原子发布、内容校验、Mirror 每次删前确认与空源保护，以及单向同步的能力边界。
- **[故障排查与日志](troubleshooting.md)** — 看懂任务与目标状态、查看“同步日志”与运行记录、常见问题处理及安全重置配置。
