# 快速上手

[English](../getting-started.md) | 简体中文

SyncMaid 将一个**源文件夹**单向同步到一个或多个**目标文件夹**：始终以源目录为准，目标目录跟随同步。你可以点击**运行**手动执行，也可以设置 Cron 定时或监视源目录变更自动触发。

## 安装与准备

SyncMaid 发布为单个可执行文件 `SyncMaid.exe`，无需安装程序或额外运行时——把它复制到任意可写的本地目录（例如用户目录或其它磁盘分区）即可双击运行。

程序采用**便携模式**：所有持久化数据都存放在 `SyncMaid.exe` 同级的 `Data` 文件夹中（需位于支持标准目录对象标识和文件锁的本地固定或可移动 NTFS、ReFS、FAT/exFAT 卷）。整体搬迁该目录即可带走全部任务与设置，不会在系统中遗留任务配置。参见 [存储说明](settings.md#存储)。

## 创建第一个任务

1. 点击顶部**新建任务**。
2. 在**此任务做什么**下选择**同步**或**移动**（“同步”复制文件并保留源目录不动；“移动”在目标校验发布成功后移除源文件）。
3. 填写**任务名称**（例如 `照片备份到 NAS`）。
4. 通过**浏览**选择**源文件夹**（或直接输入其绝对路径）。
5. 触发方式先保持**Manual手动**——等手动试跑符合预期后再切为监视或定时。
6. 点击**保存任务**。

此时任务卡片会出现在主界面上，显示为**Manual手动**和**尚未添加目标**；在添加目标前不会对磁盘做任何文件写入。

## 添加目标

1. 在任务卡片上点击管理/编辑目标，点击**添加目标**。
2. 填写**目标名称**，点击**浏览**选择已存在的**目标文件夹**（目标目录必须独立于源目录之外：既不能位于源目录内，也不能包含源目录）。
3. 设置该目标的同步策略：
   - 对于**同步任务**，可选：
     - **仅添加（Add-only）**：只复制新增和变更的文件，从不删除目标中的已有文件。
     - **Mirror镜像**：同步源目录中的全部文件；每次需要移除目标多余文件前都必须经过用户明确确认。
   - 对于**移动任务**，所有目标统一执行**Move**：选择冲突处理（**保留源**或**加编号**）以及目录策略（**保留目录结构**或**平铺到目标根目录**）。
4. 按需设置**此目标的文件过滤**（可通过**源预览**在不写盘的情况下检查哪些文件会被匹配）。
5. 点击目标行上的确认按钮应用行修改，再点击**保存**提交。

如果是第一次使用，推荐从**同步任务 + 仅添加**开始，这种组合绝不会删除任何文件。详见 [任务与目标](tasks-and-destinations.md#同步策略)。

## 执行同步

点击任务卡片上的运行按钮（`▷`）。运行期间可实时查看进度和传输字节数；结束后，每个目标行会更新状态（如 `刚刚同步 · N个文件`），任务卡片汇总为**全部已同步**、**部分目标已完成**或具体的失败信息。

## 一个任务多个目标

再次点击**添加目标**即可把同一份源目录同时分发到多个位置——例如一份使用**Mirror镜像**做完整备份，另一份使用**仅添加**按条件复制筛选后的文件。每个目标拥有独立策略、独立过滤规则和独立运行记录。

而在**移动任务**中，多个目标组成有序规则列表，每个源文件只会进入**首个匹配它的目标**并从源目录中移除。

## 配置保存在哪里

所有任务配置、通用设置、界面语言及运行记录都保存在 `SyncMaid.exe` 同级的 `Data` 目录中（包括 `tasks-go.json`、`settings-go.json`、`locale`、`run-history-go.json`）。详见 [存储说明](settings.md#存储)。
