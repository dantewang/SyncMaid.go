SyncMaid.go 0.1.0 — Windows amd64 本地便携试用

将整个SyncMaid目录解压到可写的本地固定NTFS卷，再打开SyncMaid.exe。
首次界面可在左下角齿轮设置中选择简体中文。运行只需要EXE；licenses为第三方许可说明。
程序在EXE旁创建Data和协调锁文件，不需要安装器。关闭到托盘默认关闭，关闭窗口会等待清理并退出。
请先用自己新建的测试源/目标目录试用。Move会在目标验证后永久移除源；Mirror移除必须逐次确认。

此包是本机试用，尚非正式发布，也未经过干净Windows兼容或代码签名验收。
安装和 Data 可使用本地固定或可移动 NTFS/ReFS/FAT/exFAT 卷，需具备可确认身份及独占锁。当前实测固定 NTFS，尚无 USB/exFAT/ReFS 测试卷。网络共享仅可尝试作同步端点，需支持身份检查和句柄相对文件操作。共享源 Watch 每5秒轮询。共享或可移动目标无法使用回收站模式；程序不会自动执行永久删除。
使用旧 Rust 任务前请退出旧版。同一会话、同一 Data 路径的兼容锁可防常见双开，不保护其它独立副本。导入需显式选择，不会修改旧文件。设置可导入旧窗口偏好，并打开旧状态和日志文件查阅。
不要把早期Go开发版直接用于新格式Data；先保留原文件。损坏配置不会自行变空或回退；备份可用时可在主窗确认恢复，保留损坏原文。
登录自启仅由显式设置登记；移动EXE后需重新登记，旧路径项不会自动清理。
托盘人工操作、真实IME组合、其它DPI、干净机器和四语完整视觉验收仍未完成；四语视觉验收目前延期。
请保留licenses目录。不要将自己的Data或日志包含在转发试用包中。
